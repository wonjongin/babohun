# 보훈의료 수요 기반 자원 재배치 모델과 공공의료로의 확장 가능성 분석

## □ 분석 개요

### ○ 과제명
**보훈의료 수요 기반 자원 재배치 모델과 공공의료로의 확장 가능성 분석**

### ○ 분석배경 및 목표

#### 분석 배경
보훈병원은 국가유공자와 그 유족들에게 의료서비스를 제공하는 공공의료기관으로, 지속가능한 운영과 의료서비스 질 향상이 중요한 과제입니다. 현재 보훈병원들은 다음과 같은 문제점을 안고 있습니다:

- **자원 배분의 비효율성**: 병상, 전문의, 진료비예산의 불균형한 배분
- **수요 예측의 부정확성**: 미래 의료수요에 대한 체계적인 예측 부족
- **운영 효율성 저하**: 병상가동률 저하 및 자원 낭비
- **공공의료 확장 필요성**: 일반인 유입을 통한 운영 안정성 확보

#### 분석 목표
1. **수요 예측 모델 구축**: 연령, 지역, 진료과별 미래 3년간 의료수요 예측
2. **자원 최적화 모델 개발**: 병상, 전문의, 진료비예산의 효율적 재배치
3. **시뮬레이션 기반 정책 검증**: 다양한 운영 시나리오의 효과 분석
4. **공공의료 확장 방안 제시**: 일반인 유입을 통한 운영 안정성 확보

#### 1. 데이터 통합 및 정제
- **병원별 통합 데이터 생성**: 병상수, 전문의수, 진료과별 현황 통합
- **상병코드 표준화**: ICD-10 기준 상병코드 정규화
- **결측값 처리**: 진료비 추정을 위한 상병코드별 평균값 활용

#### 2. 시계열 데이터 전처리

- **정규화**: 스케일링을 통한 변수 간 비교 가능성 확보

#### 3. 예측 모델용 특성 엔지니어링
- **연령대별 그룹화**: 10세 단위 연령대 분류
- **지역별 분류**: 보훈병원 소재 지역 기준 분류
- **진료과별 매핑**: 15개 주요 진료과로 분류

## □ 데이터 분석

### ○ 분석기법

#### 1. **시계열 분석**
- **ARIMA 모델**: 전통적 시계열 예측
- **계절성 ARIMA**: 계절적 변동성 반영
- **자동 ARIMA**: 최적 파라미터 자동 선택

#### 2. **머신러닝 기법**
- **Random Forest**: 앙상블 기반 예측
- **XGBoost**: 그래디언트 부스팅
- **Stacking**: 다중 모델 앙상블
- **ElasticNet**: 정규화된 선형 회귀

#### 3. **최적화 기법**
- **PuLP 정수계획법**: 자원 배분 최적화
- **목적함수**: 총 비용 최소화 및 효율성 극대화
- **제약조건**: 병상수, 전문의수, 예산 한계

#### 4. **시뮬레이션**
- **SimPy**: 이산사건 시뮬레이션
- **병원 운영 모델링**: 환자 도착, 진료, 퇴원 프로세스
- **다중 시나리오 분석**: 다양한 운영 조건 시뮬레이션
